# Definition of Ready

- Source: `08-roadmap-and-epics.md` §7 (ecosystem plan, 2026-10-09). Change it there first.
- A story enters a sprint only when every item is true.

| # | Item |
|---|---|
| R1 | The story has an ID (`S-Ex-nn`), a title in imperative form, and an epic. |
| R2 | Acceptance criteria are testable and written in ASD-STE100. |
| R3 | Size is ≤ 1 sprint. Larger work is split. |
| R4 | Dependencies are done, or a stub or fake exists. |
| R5 | API or event changes are drafted in `synthwerk-contracts`. |
| R6 | Affected FR/NFR IDs are listed. |
| R7 | Open questions that block the story have an answer or a logged decision. |
| R8 | Security and privacy impact is noted (none, low, high). High needs an ADR. |
